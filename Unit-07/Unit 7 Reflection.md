Applying these goals to web design, I realized that websites can serve a purpose beyond aesthetics—they can raise awareness, share information, and inspire change. I practiced using design thinking to identify user needs and create a community-focused project that supports a global goal. This unit showed me that coding is not just about building pages; it is about solving problems and creating impactful, purpose-driven experiences. It has inspired me to design projects that are both functional and meaningful.
